# AUTH AND ONBOARDING FLOWS
Door A, Invitation (main path for paying clients):
1. Paystack webhook confirms deposit -> in one DB transaction create Client, User(contact), Engagement, Invitation.
2. Send invite email: "Payment received", package name, button "Set up your portal" -> /accept-invite?token=...
3. Accept-invite page: email/company/package pre-filled and read-only; choose password OR Google OR magic link; checkbox to accept Terms and Privacy (store timestamp + version). No separate email verification needed because the invite proves ownership.
4. Welcome step (/portal/welcome): full name, WhatsApp number, job title, notification preference (email/WhatsApp/both), timezone default Africa/Lagos.
5. Package onboarding wizard: multi-step, autosaves every step, resumable, skippable ("Do this later"), progress % per engagement. Questions differ by tier:
   - Get Visible: business name, 3 domain options, preferred email address, bio/services, social links, WhatsApp number, reference sites.
   - Look Professional: all above + brand colors/tone, existing logo, sitemap for 3-5 pages, Google Business details, up to 3 email account names.
   - Launch Ready / Build Authority: all above + audience, competitors, values, tagline, team details, product/service content, blog topics, newsletter tool.
   Never collect passwords; use an access-request checklist (e.g. "add us as manager on your Google Business Profile").
6. Redirect to dashboard.

Door B, Self sign-up (prospects): /signup (name, email, phone, password or Google, honeypot, rate limit) -> email verification (6-digit code or link) -> "What brings you here?" (website/brand package | LED billboard | not sure) -> short business profile that creates a Lead and alerts admin -> dashboard in "prospect" state. When a quote is accepted and paid, UPGRADE the same account by attaching Client + Engagement. Never create a second account.

Login: password, Google, magic link. Same error for wrong email/wrong password. Rate limiting and temporary lockout. Forgot-password link is single-use, 1 hour. Sessions about 30 days with "log out of all devices". Optional 2FA for ADMIN/STAFF.

Post-login redirect function:
  non-client -> /admin; unverified -> /verify-email; profile incomplete -> /portal/welcome; else -> /portal/dashboard.
Unfinished onboarding must NOT block the dashboard; show it as a checklist banner.

Edge cases to handle: expired invite (offer resend to the invited email only), already-used invite (redirect to login), signup with an email that has a pending invite (merge after verification), login before deposit clears (prospect dashboard with "Payment pending"), bank-transfer payments (admin marks received -> same invite trigger), admin changes client email (re-verify), contact leaves company (deactivate, keep history), OWNER can invite MEMBERs from Settings > Team.
